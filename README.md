## The sentence

> Imagine every library and post office on earth joined by roads of light, so a letter you write at your table is read in China before your kettle boils.

151 characters, one sentence. It explains the modern internet using only
things a person from 1800 already knows — libraries, post offices, roads,
letters, a kettle — with no word coined after their time.

## How it works

Run it exactly as the grader does:

```sh
node main.ts
```

`main.ts` checks the sentence (1–200 characters, exactly one sentence, no
post-1800 words) and writes it to `/output/entry.txt`, verifying the written
file byte for byte. It never removes the output directory itself, only the
files inside it.
